## Working With AI-Generated Code

I also work with code that has been created or assisted by tools such as ChatGPT, Cursor, Claude, and GitHub Copilot.

Sometimes AI-generated code works well. Sometimes it creates problems that aren't immediately obvious.

If you already have an AI-generated application that isn't working properly, I can go through the existing code, understand what's happening, find the problem, and fix it instead of starting everything again.

## How I Approach Problems

I prefer to understand the problem first instead of immediately changing code.

Usually I:

1. Look at the existing code and understand how it works
2. Reproduce or identify the problem
3. Find the actual cause
4. Make the necessary changes
5. Test the result
6. Clean up anything that needs improvement
